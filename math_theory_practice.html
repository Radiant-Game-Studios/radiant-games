Полная теория по всем типам задач

Здесь собраны все методы и формулы для решения задач из вашего списка.
Интегралы записаны в виде ∫[a..b] f(x) dx, производные — f_x, f_xy и т.д.
Подходит для копирования в блокнот, Word или любой текстовый редактор.

1. Площадь плоской фигуры через определённый интеграл

Суть: площадь между двумя кривыми или под одной кривой.

Декартовы координаты: фигура ограничена сверху y = f(x), снизу y = g(x), слева x = a, справа x = b.

S = ∫[a..b] (f(x) − g(x)) dx

Параметрический способ: x = φ(t), y = ψ(t), t₁ ≤ t ≤ t₂.

S = ∫[t₁..t₂] ψ(t) · φ'(t) dt (знак выбирается так, чтобы площадь была положительной).

Полярные координаты: r = r(φ), α ≤ φ ≤ β.

S = ½ ∫[α..β] [r(φ)]² dφ

Примечание: если фигура состоит из нескольких частей, площадь суммируется.

2. Длина дуги кривой через определённый интеграл

Декартовы: y = f(x), a ≤ x ≤ b.

L = ∫[a..b] √(1 + (f'(x))²) dx

Параметрические: x = φ(t), y = ψ(t), t₁ ≤ t ≤ t₂.

L = ∫[t₁..t₂] √(φ'(t)² + ψ'(t)²) dt

Полярные: r = r(φ), α ≤ φ ≤ β.

L = ∫[α..β] √(r(φ)² + (r'(φ))²) dφ

Примечание: если кривая задана неявно, иногда проще перейти к параметрическому виду.

3. Объём тела вращения через интеграл

Вращение вокруг OX: y = f(x), a ≤ x ≤ b.

V = π ∫[a..b] [f(x)]² dx

Вращение вокруг OY (метод обратной функции): x = g(y), c ≤ y ≤ d.

V = π ∫[c..d] [g(y)]² dy

Вращение вокруг OY (метод цилиндрических оболочек):

V = 2π ∫[a..b] x · f(x) dx

Примечание: метод оболочек удобен, когда трудно выразить x через y.

4. Частные производные 1-го и 2-го порядков

Первые производные:
f_x = ∂f/∂x — дифференцируем по x, считая y постоянной.
f_y = ∂f/∂y — дифференцируем по y, считая x постоянной.

Вторые производные:
f_xx = ∂/∂x (f_x)    (дважды по x)
f_yy = ∂/∂y (f_y)    (дважды по y)
f_xy = ∂/∂y (f_x)    (сначала по x, потом по y)
f_yx = ∂/∂x (f_y)    (сначала по y, потом по x)

Важно: если смешанные производные непрерывны, то f_xy = f_yx.

5. Дифференциал 1-го и 2-го порядка функции нескольких переменных

Первый дифференциал: df = f_x dx + f_y dy

Второй дифференциал: d²f = f_xx dx² + 2 f_xy dx dy + f_yy dy²

Примечание: дифференциалы используются для приближённых вычислений и в задачах на экстремум.

6. Локальный экстремум функции 2-х переменных

Алгоритм:
1. Найти стационарные точки из системы f_x = 0, f_y = 0.
2. Вычислить вторые производные в каждой точке.
3. Найти дискриминант D = f_xx·f_yy − (f_xy)².
4. Если D > 0 и f_xx > 0 → минимум.
Если D > 0 и f_xx < 0 → максимум.
Если D < 0 → седло (нет экстремума).
Если D = 0 → нужны дополнительные исследования.

7. Условный экстремум функции 2-х переменных (метод множителей Лагранжа)

Задача: найти экстремум f(x, y) при условии g(x, y) = 0.

Метод:
Составляем функцию Лагранжа: L(x, y, λ) = f(x, y) + λ·g(x, y)
Решаем систему:
L_x = 0, L_y = 0, g(x, y) = 0.
Найденные точки (x, y) — кандидаты на условный экстремум.
Для проверки можно сравнить значения f или использовать второй дифференциал L.

8. Расстановка пределов интегрирования в двойном интеграле в разных порядках

Порядок dy dx (сначала по y, потом по x):
∫[x=a..b] ∫[y=y₁(x)..y₂(x)] f(x, y) dy dx
Где a и b — min и max x в области, y₁(x) и y₂(x) — нижняя и верхняя границы при фиксированном x.

Порядок dx dy (сначала по x, потом по y):
∫[y=c..d] ∫[x=x₁(y)..x₂(y)] f(x, y) dx dy
Где c и d — min и max y, x₁(y) и x₂(y) — левая и правая границы.

Совет: всегда рисуйте область, даже мысленно.

9. Изменение порядка интегрирования в двойном интеграле

Шаги:
1. По исходным пределам восстановить область D.
2. Нарисовать D.
3. Описать D в другом порядке (найти новые пределы).
4. Записать интеграл с новыми пределами.

Пример: дан ∫[0..1] dx ∫[x²..x] f dy → область между параболой y=x² и прямой y=x, x от 0 до 1. В другом порядке: ∫[0..1] dy ∫[y..√y] f dx.

10. Вычисление двойного интеграла в декартовых и полярных координатах

Декартовы: расставить пределы и вычислить последовательно.

Полярные координаты:
x = r·cos φ, y = r·sin φ, dx dy = r dr dφ.
∬_D f(x, y) dxdy = ∫[φ=α..β] ∫[r=r₁(φ)..r₂(φ)] f(r·cos φ, r·sin φ)· r dr dφ.
Пределы: φ — угол, r — расстояние от начала координат.

Когда использовать полярные: область — круг, кольцо, сектор, или подынтегральная функция содержит x²+y².

11. Вычисление тройного интеграла в разных системах координат

Декартовы: ∫∫∫_T f dxdydz = ∫[x=a..b] ∫[y=y₁(x)..y₂(x)] ∫[z=z₁(x,y)..z₂(x,y)] f dz dy dx.

Цилиндрические:
x = r·cos φ, y = r·sin φ, z = z, dV = r dr dφ dz.
∫∫∫_T f dV = ∫[φ=α..β] ∫[r=r₁(φ)..r₂(φ)] ∫[z=z₁(r,φ)..z₂(r,φ)] f(r·cos φ, r·sin φ, z)· r dz dr dφ.

Сферические:
x = ρ·sin θ·cos φ, y = ρ·sin θ·sin φ, z = ρ·cos θ, dV = ρ² sin θ dρ dθ dφ.
Здесь ρ ≥ 0 — расстояние от начала, 0 ≤ θ ≤ π — угол от оси Z, 0 ≤ φ ≤ 2π — азимут.
∫∫∫_T f dV = ∫[φ=α..β] ∫[θ=θ₁..θ₂] ∫[ρ=ρ₁(θ,φ)..ρ₂(θ,φ)] f(···)· ρ² sin θ dρ dθ dφ.

12. Криволинейный интеграл 1-го рода (по длине дуги)

Суть: интегрирование скалярной функции вдоль кривой.

Формула (параметрическая):
∫_L f(x, y) ds = ∫[t₁..t₂] f(x(t), y(t))·√(x'(t)² + y'(t)²) dt
Для явной y = y(x): ds = √(1 + (y')²) dx.
Для полярной r = r(φ): ds = √(r² + (r')²) dφ.

Применение: масса проволоки, длина дуги, центр масс.

13. Криволинейный интеграл 2-го рода (по координатам)

Суть: работа силы вдоль кривой, циркуляция.

Формула (параметрическая):
∫_L P dx + Q dy = ∫[t₁..t₂] [ P(x(t),y(t))·x'(t) + Q(x(t),y(t))·y'(t) ] dt
Важен порядок обхода кривой (направление).

Формула Грина (замкнутый контур):
∮_L P dx + Q dy = ∬_D (Q_x − P_y) dxdy, где D — область внутри L, обход против часовой стрелки.

14. Поверхностный интеграл 1-го рода (по площади поверхности)

Суть: масса оболочки, площадь поверхности.

Для явной поверхности z = z(x, y):
∬_S f dS = ∬_{D_xy} f(x, y, z(x, y))·√(1 + z_x² + z_y²) dxdy

Для параметрической поверхности r(u, v):
∬_S f dS = ∬_D f(r(u, v))·|r_u × r_v| du dv

15. Поверхностный интеграл 2-го рода (по проекциям)

Суть: поток векторного поля через поверхность.

Для верхней стороны z = z(x, y):
∬_S R(x, y, z) dx dy = ∬_{D_xy} R(x, y, z(x, y)) dxdy
Знак "+" для верхней стороны, "−" для нижней.

Полный поток:
∬_S P dy dz + Q dz dx + R dx dy = ∬_S (P, Q, R)·n dS

Формула Остроградского-Гаусса (замкнутая поверхность):
∯_S F·n dS = ∭_V div F dV, где div F = P_x + Q_y + R_z

16. Производная по направлению, градиент, циркуляция, ротор, поток векторного поля

Градиент: ∇f = (f_x, f_y, f_z) — направление наибольшего роста функции.
Производная по направлению единичного вектора l₀: ∂f/∂l = ∇f · l₀.

Ротор (вихрь): ∇ × F = (R_y − Q_z, P_z − R_x, Q_x − P_y).
Характеризует вращение поля.

Циркуляция: Γ = ∮_L F·dr = ∮_L P dx + Q dy + R dz.
По теореме Стокса: Γ = ∬_S (∇ × F)·n dS.

Поток: Φ = ∬_S F·n dS.
По теореме Гаусса: для замкнутой поверхности Φ = ∭_V div F dV.

Примечание: все эти величины связаны между собой теоремами векторного анализа.

Совет для подготовки: на каждый тип задач сначала выучите формулы, затем решайте по 2-3 простых примера, постепенно усложняя. Удачи!
