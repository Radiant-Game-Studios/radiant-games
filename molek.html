📘 Молекулярная физика
Полные ответы на экзаменационные вопросы (1–19)

Вопрос 1. Законы идеального газа. Вывод уравнения Менделеева-Клапейрона. Закон Авогадро. Изопроцессы (формулы и графики). Вывод закона Дальтона. Молярная масса смеси.

1. Вывод уравнения Менделеева-Клапейрона

Из основного уравнения МКТ и связи параметров состояния известно, что давление газа:

P = n * k * T

По определению, концентрация частиц n = N / V, где N — общее число молекул в объеме V. Подставим это выражение:

P = (N / V) * k * T => P * V = N * k * T

Выразим общее число частиц через количество вещества (ν): N = ν * N_A = (m / M) * N_A, где N_A — число Авогадро. Тогда:

P * V = (m / M) * N_A * k * T

Произведение постоянной Больцмана на число Авогадро дает универсальную газовую постоянную: R = k * N_A = 8.31 Дж/(моль*К). Подставляя R, получаем искомое уравнение состояния идеального газа:

P * V = (m / M) * R * T

2. Закон Авогадро

Из соотношения P = n * k * T следует, что при одинаковых давлениях (P) и температурах (T) концентрация молекул (n) любых газов одинакова. Так как n = N / V, то в равных объемах различных газов при одинаковых температуре и давлении содержится одинаковое число молекул.

3. Изопроцессы (Законы, формулы и графики)

📈 Изохорный (V = const)

Закон Шарля: P/T = const

📈 Изобарный (P = const)

Закон Гей-Люссака: V/T = const

📈 Изотермический (T = const)

Закон Бойля-Мариотта: P·V = const

4. Вывод закона Дальтона и молярная масса смеси

Пусть в сосуде объемом V находится смесь газов с числом частиц N_1, N_2, ... N_n. Общее давление смеси определяется суммарной концентрацией частиц n_см = Σn_i:

P_см = n_см * k * T = (n_1 + n_2 + ... + n_n) * k * T = n_1*k*T + n_2*k*T + ... + n_n*k*T

Каждое слагаемое вида P_i = n_i * k * T представляет собой парциальное давление — давление, которое оказывал бы данный газ смеси, если бы он один занимал весь объем. Отсюда получаем закон Дальтона:

P_см = P_1 + P_2 + ... + P_n

Для определения молярной массы смеси (M_смеси) используется общая масса смеси m = Σm_i и общее число молей ν = Σν_i:

M_смеси = m / ν = (m_1 + m_2 + ...) / (ν_1 + ν_2 + ...)

В конспекте рассмотрен практический пример расчета для сухого воздуха (80% N_2 и 20% O_2):

M_смеси = 1 / [ (0.8 / M_N2) + (0.2 / M_O2) ] ≈ 28.7 г/моль

Вопрос 2. Давление газа. Вывод основного уравнения молекулярно-кинетической теории идеального газа. Формулы внутренней энергии идеального газа и средней квадратичной скорости. Распределение энергии по степеням свободы.

1. Вывод основного уравнения МКТ

Рассмотрим удар отдельной молекулы массой m_0, движущейся со скоростью v перпендикулярно стенке сосуда площади S. При упругом столкновении молекула передает стенке импульс:

Δp₁ = m_0*v - (-m_0*v) = 2*m_0*v

За время Δt до стенки долетят лишь те молекулы, которые находятся внутри цилиндра объемом V = S * v * Δt. Число таких молекул равно n * S * v * Δt (где n — концентрация). Из-за хаотичности теплового движения по трем пространственным осям (вдоль и против направления оси Х) к выбранной стенке движется лишь 1/6 часть всех молекул:

N_ударов = (1/6) * n * S * v * Δt

Суммарный импульс, переданный площадке за время Δt:

Δp_сум = N_ударов * Δp₁ = (1/6) * n * S * v * Δt * (2*m_0*v) = (1/3) * n * m_0 * v^2 * S * Δt

По второму закону Ньютона в импульсной форме, сила давления газа равна F = Δp_сум / Δt. Тогда давление газа P = F / S:

P = (1/3) * n * m_0 * <v^2>

Так как средняя кинетическая энергия поступательного движения молекулы равна <E_к> = (m_0 * <v^2>) / 2, то основное уравнение МКТ принимает вид:

P = (2/3) * n * <E_к>

2. Формулы средней квадратичной скорости и внутренней энергии

Сопоставляя P = (2/3)*n*<E_к> и P = n*k*T, находим среднюю кинетическую энергию одной молекулы: <E_к> = (3/2)*k*T. Расписав энергию через массу и скорость, получаем формулу для средней квадратичной скорости:

v_ср.кв = √<v^2> = √(3*k*T / m_0) = √(3*R*T / M)

Внутренняя энергия (U) идеального газа — это сумма кинетических энергий всех его ν молей частиц (потенциальное взаимодействие молекул идеального газа принято равным нулю):

U = N * <E_к> = ν * N_A * (3/2)*k*T = (3/2) * ν * R * T

3. Распределение энергии по степеням свободы (закон равнораспределения)

На каждую степень свободы (возможные независимые направления движения) молекулы в среднем приходится одинаковая кинетическая энергия, равная (1/2)*k*T. В общем случае для молекулы с числом степеней свободы i:

  • Одноатомный газ: i = 3 (3 поступательные степени свободы).
  • Двухатомный газ: i = 5 (3 поступательные + 2 вращательные).
  • Многоатомный газ: i = 6 (3 поступательные + 3 вращательные).
<E> = (i/2) * k * T  |  U = (i/2) * ν * R * T

Вопрос 3. Вывод барометрической формулы. Вывод распределения Больцмана. Опыт Перрена по определению числа Авогадро.

1. Вывод барометрической формулы

Рассмотрим вертикальный столб газа площади сечения S в однородном поле тяжести (g = const). Выделим малый слой газа высотой Δh, заключенный между высотами h и h + Δh. Разность давлений на нижнюю и верхнюю границы слоя вызвана весом заключенного в нем газа:

P(h) * S - P(h + Δh) * S = m_слоя * g => -ΔP = (m_слоя * g) / S

Массу газа в слое запишем через плотность ρ и объем ΔV = S * Δh: m_слоя = ρ * S * Δh. Из уравнения Менделеева-Клапейрона выразим плотность: ρ = m/V = (P * M) / (R * T). Подставим эти значения:

-ΔP = ρ * g * Δh = [ (P * M * g) / (R * T) ] * Δh

Переходя к бесконечно малым приращениям (Δh -> dh, ΔP -> dP), разделяем переменные:

dP / P = - (M * g / (R * T)) * dh

Интегрируем левую часть от P_0 (давление на высоте h=0) до P, а правую — от 0 до h:

ln(P / P_0) = - (M * g * h) / (R * T)

Потенциируя выражение, получаем барометрическую формулу:

P = P_0 * exp( - (M * g * h) / (R * T) )

2. Вывод распределения Больцмана

Поскольку давление газа пропорционально его концентрации (P = n * k * T, P_0 = n_0 * k * T), подставим данные равенства в барометрическую формулу:

n * k * T = n_0 * k * T * exp( - (M * g * h) / (R * T) )

Разделим обе части на k * T. Учитывая связи макро- и микрохарактеристик: M = m_0 * N_A и R = k * N_A, отношение молярной массы к газовой постоянной преобразуется к массе одной молекулы и постоянной Больцмана: M / R = m_0 / k. Получаем закон распределения концентрации молекул по высотам:

n = n_0 * exp( - (m_0 * g * h) / (k * T) )

Так как произведение m_0 * g * h — это потенциальная энергия E_п одиночной молекулы в поле тяжести Земли, выражение приобретает канонический вид распределения Больцмана:

n = n_0 * exp( - E_п / (k * T) )

3. Опыт Перрена

Жан Перрен использовал распределение Больцмана для исследования взвешенных в воде мелких сферических частиц гуммигута (броуновских частиц). Заменив силу тяжести на эффективную силу с учетом выталкивающей силы Архимеда, потенциальная энергия частицы приняла вид E_п = V_ч * (ρ_ч - ρ_жидк) * g * h. Подсчитывая число броуновских частиц на разных микроскопических высотах с помощью микроскопа, Перрен экспериментально подтвердил распределение Больцмана и с высокой точностью определил значение постоянной Авогадро N_A.

Вопрос 4. Распределение молекул газа по скоростям (распределение Максвелла). Физический смысл функции распределения. Условие нормировки. Наиболее вероятная скорость и значение функции распределения при этой скорости. Функция распределения для относительной скорости. Условия существования атмосферы планет.

1. Физический смысл и формула распределения Максвелла

Распределение Максвелла задает долю частиц dN / N, абсолютные скорости которых лежат в интервале от v до v + dv:

dN / N = F(v) * dv

где F(v) — плотность вероятности или функция распределения молекул по скоростям. Полный вид функции:

F(v) = 4π * ( m_0 / (2π * k * T) )^(3/2) * v^2 * exp( - (m_0 * v^2) / (2 * k * T) )

2. Условие нормировки

Так как сумма вероятностей всех возможных значений скорости равна единице (интеграл берется по всему диапазону скоростей от 0 до бесконечности), выполняется соотношение:

∫[0; ∞] F(v) dv = 1

3. Наиболее вероятная скорость

Для поиска максимума функции распределения (наиболее вероятной скорости v_в) необходимо взять производную от F(v) по v и приравнять её к нулю: dF(v)/dv = 0. Проведя дифференцирование выражения, получаем:

v_в = √(2 * k * T / m_0) = √(2 * R * T / M)

Подставим найденное значение v_в обратно в исходную функцию распределения F(v), чтобы найти ординату максимума:

F(v_в) = (4 / √π) * (1 / v_в) * exp(-1) ∝ 1 / √T

4. Функция для относительной скорости и атмосфера планет

Введение безразмерной относительной скорости u = v / v_в позволяет переписать распределение в инвариантном виде, не зависящем от рода газа и температуры.

Условие существования атмосферы: Молекулы удерживаются планетой, если их тепловые скорости значительно меньше второй космической скорости (скорости убегания) для данной планеты. Согласно распределению Максвелла, всегда существует малая доля быстрых частиц в "хвосте" распределения, скорости которых выше критической. Это приводит к постепенному "диссипированию" (улетучиванию) атмосферы планеты.

Вопрос 5. Эффективные диаметр и сечение молекулы. Вывод формул для средней длины свободного пробега и числа столкновений и оценка порядка этих величин. Вакуум.

1. Эффективный диаметр и сечение

  • Эффективный диаметр (d): минимальное расстояние, на которое могут сблизиться центры двух сталкивающихся молекул. Порядок величины: 10^(-10) м.
  • Эффективное сечение (σ): площадь круга радиуса d: σ = π * d².

2. Вывод формул числа столкновений и длины свободного пробега

Пусть молекула движется со средней скоростью ⟨v⟩. За время t она проходит путь ⟨v⟩*t. Столкновение произойдет с любой частицей, центр которой лежит внутри "цилиндра столкновений" объема V_цил = σ * ⟨v⟩ * t. Среднее число столкновений за время t равно числу частиц в этом объеме (при концентрации n):

N_столк = n * V_цил = n * π * d² * ⟨v⟩ * t

С учетом относительного движения всех остальных молекул среды, точный статистический вывод дает дополнительный множитель √2 для относительной скорости. Средняя частота столкновений (число ударов в единицу времени) равна:

ν_столк = √2 * π * d² * n * ⟨v⟩

Средняя длина свободного пробега (λ) — среднее расстояние, проходимое молекулой между двумя последовательными соударениями:

λ = ⟨v⟩ * t / N_столк = 1 / (√2 * π * d² * n)

Поскольку при постоянной температуре концентрация прямо пропорциональна давлению (n = P / (k*T)), длина свободного пробега обратно пропорциональна давлению газа: λ ∝ 1 / P.

Оценка порядка величин (для нормальных условий): λ ≈ 10^(-7) м, число столкновений ν_столк ≈ 10^9 с^(-1).

3. Понятие вакуума

Вакуум (ультраразреженный газ) — состояние газа, при котором средняя длина свободного пробега молекул λ становится соизмеримой или существенно превышает характерные линейные геометрические размеры L рабочего сосуда (λ ≫ L). В этом состоянии молекулы практически не сталкиваются друг с другом, а испытывают удары только о стенки сосуда.

Вопрос 6. Явления переноса. Диффузия в газах. Закон Фика. Расчёт коэффициента самодиффузии.

1. Явления переноса

Процессы, возникающие при нарушении термодинамического равновесия макросистемы и сопровождающиеся направленным переносом массы, импульса или внутренней энергии, называются явлениями переноса. Данные процессы термодинамически необратимы.

2. Диффузия и закон Фика

Диффузия — явление самопроизвольного выравнивания концентраций компонентов смеси, обусловленное тепловым хаотическим движением молекул. Направленный перенос массы происходит из области с высокой плотностью в область с низкой плотностью. Экспериментальный закон Фика для одномерного случая (перенос вдоль оси Z) имеет вид:

M = - D * (dρ / dz) * S * t

где M — переносимая масса, S — площадь площадки, t — время, dρ/dz — градиент плотности вещества, а знак "минус" указывает направление переноса в сторону уменьшения плотности. D — коэффициент диффузии.

3. Расчет теоретического коэффициента самодиффузии

Рассмотрим воображаемую плоскость Z в газе. Из-за хаотичности теплового движения в трех измерениях, среднее число молекул, пролетающих через площадку S в одном направлении за единицу времени, оценивается как (1/6)*n*S*⟨v⟩. Молекулы переносят свойства того слоя, в котором произошло их последнее соударение (на расстоянии длины свободного пробега λ до площадки, т.е. из точек z - λ и z + λ). Разность встречных потоков молекул дает суммарный диффузионный поток частиц:

N_сум = (1/6)*S*⟨v⟩ * [ n(z - λ) - n(z + λ) ]

Используя разложение в ряд Тейлора: n(z - λ) - n(z + λ) ≈ - 2*λ * (dn / dz), подставим приращение:

N_сум = (1/6)*S*⟨v⟩ * ( - 2*λ * (dn / dz) ) = - (1/3) * ⟨v⟩ * λ * (dn / dz) * S

Умножив число частиц на массу одной молекулы m_0 (переходя к массе газа M = N_сум * m_0 * t и плотности ρ = n * m_0), сопоставляем выражение с экспериментальным законом Фика. Получаем теоретическое значение коэффициента самодиффузии:

D = (1/3) * ⟨v⟩ * λ

Вопрос 7. Внутреннее трение. Формула Ньютона. Кинематическая и динамическая вязкости. Теплопроводность. Закон Фурье. Связь между коэффициентами переноса.

1. Внутреннее трение (Вязкость) и формула Ньютона

Внутреннее трение возникает при относительном движении параллельных слоев газа или жидкости, движущихся с разными скоростями u. Из-за теплового хаотического движения происходит непрерывный обмен молекулами между соседними слоями, что ведет к переносу направленного импульса и выравниванию скоростей слоев. Экспериментальный закон выражается формулой Ньютона:

F_тр = η * |du / dz| * S

где η (эта) — динамическая вязкость, а du/dz — градиент скорости направленного течения.

Аналогично выводу диффузии, молекулы переносят импульс направленного движения m_0 * u из слоев z ± λ. Теоретический расчет силы трения как изменения импульса в единицу времени дает формулу для динамической вязкости:

η = (1/3) * ⟨v⟩ * λ * ρ

Кинематическая вязкость (ν_кин): отношение динамической вязкости газа к его плотности:

ν_кин = η / ρ = (1/3) * ⟨v⟩ * λ

2. Теплопроводность и закон Фурье

Если в газе создана разность температур, хаотически движущиеся молекулы осуществляют перенос внутренней энергии (тепла) от более нагретых слоев к менее нагретым. Экспериментальный закон Фурье:

q = - ϰ * (dT / dz) * S

где q — тепловой поток (энергия в единицу времени), dT/dz — градиент температуры, ϰ (каппа) — коэффициент теплопроводности. Подсчет переносимой молекулами энергии ⟨E_к⟩ = (i/2)*k*T приводит к теоретическому выражению:

ϰ = (1/3) * ⟨v⟩ * λ * ρ * c_v

где c_v — удельная теплоемкость газа при постоянном объеме.

3. Связь между коэффициентами переноса

Все три коэффициента макроскопического переноса определяются фундаментальными микрохарактеристиками газа (⟨v⟩, λ, ρ) и жестко связаны между собой:

η = D * ρ  |  ϰ = η * c_v = D * ρ * c_v

Важное следствие: Так как плотность газа ρ ∝ P, а длина свободного пробега λ ∝ 1/P, их произведение λ * ρ остается постоянным при изменении давления. Следовательно, коэффициенты вязкости (η) и теплопроводности (ϰ) идеального газа не зависят от давления (справедливо, пока λ мало по сравнению с размерами сосуда).

Вопрос 8. Внутренняя энергия как функция состояния. Первый закон термодинамики и его различные формулировки. Вывод формулы для работы газа. Применение первого закона термодинамики к изопроцессам.

1. Внутренняя энергия (U) как функция состояния

Внутренняя энергия макросистемы состоит из суммы кинетических энергий хаотического движения всех частиц (молекул) и потенциальных энергий их взаимного взаимодействия:

U = E_кин + E_пот

Для идеального газа молекулы не взаимодействуют на расстоянии (E_пот = 0), поэтому внутренняя энергия зависит только от температуры (T) и является однозначной функцией термодинамического состояния системы. Это значит, что ее изменение ΔU в любом процессе определяется только начальным и конечным состояниями и не зависит от пути перехода:

U_1 = N * ⟨ε_к1⟩,   U_2 = N * ⟨ε_к2⟩ ⇒ ΔU = U_2 - U_1

2. Первый закон термодинамики и его формулировки

Является законом сохранения и превращения энергии для термодинамических систем. Формулировки:

  • Основная: Количество теплоты (Q), сообщенное системе, расходуется на приращение внутренней энергии системы (ΔU) и на совершение системой работы (A) против внешних сил.
  • Через бесконечно малые приращения: dQ = dU + dA (или dQ = dU + pdV), где dQ и dA являются элементарными приращениями (не полными дифференциалами), а dU — полным дифференциалом функции состояния.
  • Через вечный двигатель: Невозможен perpetuum mobile (вечный двигатель) 1-го рода, то есть такой периодически действующий двигатель, который совершал бы полезную работу в большем количестве, чем полученная им извне энергия.

3. Вывод формулы для работы газа

Рассмотрим газ под поршнем площадью S в сосуде. При расширении газа на величину dx поршень смещается под действием силы давления F = p * S. Элементарная работа dA, совершаемая газом:

dA = F * dx = (p * S) * dx

Так как изменение объема сосуда dV = S * dx, получаем выражение для элементарной работы:

dA = p * dV

Полная работа при изменении объема от V_1 до V_2 находится интегрированием:

A = ∫_{V_1}^{V_2} p * dV

4. Применение первого закона термодинамики к изопроцессам

  • Изохорный процесс (V = const ⇒ dV = 0): Работа газа dA = p * dV = 0. Первый закон ТД принимает вид:
    dQ = dU
    Все подводимое тепло идет исключительно на увеличение внутренней энергии.
  • Изобарный процесс (p = const): Работа газа равна A = p * ∫ dV = p * (V_2 - V_1) = p * ΔV. Первый закон ТД:
    dQ = dU + p * dV
    Подводимое тепло расходуется и на нагрев, и на расширение.
  • Изотермический процесс (T = const ⇒ dU = 0): Внутренняя энергия идеального газа не меняется. Первый закон ТД:
    dQ = dA
    Все подведенное к газу тепло полностью превращается в работу расширения.

Вопрос 9. Классическая теория теплоёмкости идеального газа. Молярная и удельная теплоёмкости и связь между ними. Теплоёмкости при постоянном давлении и объёме. Вывод уравнения Майера и показателя адиабаты. Физический смысл газовой постоянной R.

1. Молярная и удельная теплоемкости, связь между ними

  • Теплоемкость тела (C_тела): C_тела = dQ / dT.
  • Удельная теплоемкость (c): Теплоемкость единицы массы вещества:
    c = dQ / (m * dT)
    Единица измерения: [Дж / (кг * К)].
  • Молярная теплоемкость (C): Теплоемкость одного моля вещества:
    C = dQ / (ν * dT)
    где количество вещества ν = m / M. Единица измерения: [Дж / (моль * К)].
  • Связь между ними: С учетом того, что c = C_тела / m, а C = C_тела / ν, получаем:
    C = c * M
    или
    c = C / M
    (где M — молярная масса).

2. Молярные теплоемкости при постоянном объеме (C_v) и давлении (C_p)

  • При V = const из первого закона ТД: dQ = dU = ν * C_v * dT. Отсюда выражается элементарное приращение внутренней энергии идеального газа для любого процесса:
    dU = ν * C_v * dT
  • При p = const теплоемкость выше, так как тепло требуется и на нагрев dU, и на совершение работы расширения pdV: dQ = ν * C_p * dT.

3. Вывод уравнения Майера

Запишем выражение для молярной теплоемкости общего вида: C = dQ / (ν * dT) = (dU + p * dV) / (ν * dT).

Подставим dU = ν * C_v * dT:

C = C_v + (p / ν) * (dV / dT)

При p = const теплоемкость C становится C_p. Из уравнения состояния Менделеева-Клапейрона для 1 моля газа: p * V = R * T. Дифференцируем его по температуре при постоянном давлении: p * (dV / dT) = R.

Подставляем полученное значение p * (dV / dT) в исходное выражение для ν = 1 моль:

C_p = C_v + R   ⇒   C_p - C_v = R

Это соотношение называется уравнением Майера.

4. Физический смысл универсальной газовой постоянной R

Из уравнения Майера следует, что R = C_p - C_v. Физический смысл: Универсальная газовая постоянная R численно равна работе, которую совершает 1 моль идеального газа при изобарном нагревании на 1 Кельвин.

5. Распределение энергии по степеням свободы и показатель адиабаты (γ)

Согласно классической теории теплоемкости, на каждую степень свободы молекулы (i) приходится средняя энергия равная (1/2)*k*T. Внутренняя энергия моля газа: U = (i/2) * R * T.

Отсюда молярные теплоемкости выражаются через число степеней свободы (i):

C_v = (i / 2) * R,   C_p = C_v + R = ((i + 2) / 2) * R

Показатель адиабаты (γ): Отношение теплоемкостей C_p к C_v (коэффициент Пуассона):

γ = C_p / C_v = (i + 2) / i

Так как i > 0, то всегда γ > 1.

Вопрос 10. Адиабатический процесс. Вывод трёх формул для адиабаты. Сравнение адиабатического и изотермического процессов. Вывод формул для работы газа при адиабатическом процессе.

1. Понятие адиабатического процесса

Адиабатическим называется процесс, протекающий в термодинамической системе без теплообмена с окружающей средой (dQ = 0). Из первого закона ТД при dQ = 0 следует:

dU = -dA   ⇒   ν * C_v * dT = -p * dV

2. Вывод трех формул для адиабаты (уравнения Пуассона)

Формула 1 (в координатах T-V):
Используем уравнение состояния для замены давления: p = ν * R * T / V. Подставим в уравнение первого закона ТД:
ν * C_v * dT = -(ν * R * T / V) * dV ⇒ C_v * (dT / T) = -R * (dV / V).
Разделим на C_v и заменим R = C_p - C_v:
dT / T = -((C_p - C_v) / C_v) * (dV / V) = -(γ - 1) * (dV / V).
Интегрируем обе части: ∫ (dT / T) = -(γ - 1) * ∫ (dV / V) ⇒ ln(T) + (γ - 1)*ln(V) = ln(const).

T * V^{γ - 1} = const

Формула 2 (в координатах p-V — основное уравнение Пуассона):
Выразим температуру из уравнения Менделеева-Клапейрона: T = p * V / (ν * R). Подставим в Формулу 1:
(p * V / (ν * R)) * V^{γ - 1} = const. Убирая константы ν и R в правую часть, получаем:

p * V^{γ} = const

Формула 3 (в координатах T-p):
Выразим объем V = ν * R * T / p и подставим в Формулу 2:
p * (ν * R * T / p)^{γ} = const ⇒ p * T^{γ} / p^{γ} = const ⇒ p^{1-γ} * T^{γ} = const. Извлечем корень степени γ:

T * p^{(1-γ)/γ} = const   (или T^{γ} * p^{1-γ} = const)

3. Сравнение адиабатического и изотермического процессов

На p-V диаграмме изотерма описывается уравнением p ~ 1/V, а адиабата — p ~ 1/V^{γ}. Поскольку γ > 1, при увеличении объема давление в адиабатическом процессе падает быстрее, чем в изотермическом. Это происходит потому, что при адиабатическом расширении давление падает не только из-за роста объема, но и из-за охлаждения газа (так как работа совершается за счет внутренней энергии).

Графическое представление на p-V диаграмме:
Изотерма: p = const / V (более пологая кривая)
Адиабата: p = const / Vγ (более крутая кривая, уходящая вниз быстрее изотермы)

4. Вывод формул для работы газа при адиабатическом процессе

Поскольку dA = -dU, работа газа равна изменению внутренней энергии с противоположным знаком: A = -ΔU = U_1 - U_2 = ν * C_v * (T_1 - T_2). Подставим C_v = R / (γ - 1):

A = ν * R * (T_1 - T_2) / (γ - 1)

Используя соотношения p_1*V_1 = ν*R*T_1 и p_2*V_2 = ν*R*T_2, формулу можно переписать через параметры давления и объема:

A = (p_1 * V_1 - p_2 * V_2) / (γ - 1) = (p_1 * V_1 / (γ - 1)) * [1 - (V_1 / V_2)^{γ - 1}]

Вопрос 11. Политропический процесс. Частные случаи. Вывод формулы политропы. Вывод частных формул из уравнения политропы.

1. Понятие политропического процесса

Политропическим называется термодинамический процесс, в ходе которого теплоемкость макросистемы остается строго постоянной (C = const).

2. Вывод формулы политропы (уравнения политропы)

Запишем первый закон ТД: dQ = dU + dA. Выразим величины через молярную теплоемкость процесса (C) и теплоемкость при постоянном объеме (C_v) для ν = 1 моль вещества:
C * dT = C_v * dT + p * dV ⇒ (C - C_v) * dT = p * dV.
Из уравнения состояния Менделеева-Клапейрона продифференцируем p*V = R*T в общем виде: p*dV + V*dp = R*dT ⇒ dT = (p*dV + V*dp) / R.
Подставим dT в уравнение первого закона:
(C - C_v) * (p*dV + V*dp) / R = p * dV.
Раскроем R через уравнение Майера R = C_p - C_v и перенесем члены:
(C - C_v) * (p*dV + V*dp) = (C_p - C_v) * p * dV ⇒ (C - C_v)*V*dp + (C - C_v)*p*dV - (C_p - C_v)*p*dV = 0.
Приведем подобные при p*dV:
(C - C_v)*V*dp + (C - C_p)*p*dV = 0.
Разделим обе части уравнения на (C - C_v)*p*V:
dp / p + ((C - C_p) / (C - C_v)) * (dV / V) = 0.
Введем константу n, называемую показателем политропы: n = (C - C_p) / (C - C_v).
Тогда дифференциальное уравнение примет вид: dp / p + n * (dV / V) = 0. Интегрируя, получаем уравнение политропы в координатах p-V:

p * V^{n} = const

3. Частные случаи политропического процесса (вывод из общего уравнения)

В зависимости от значения теплоемкости C, показатель политропы n принимает различные значения, превращая уравнение политропы в уравнения известных изопроцессов:

ПроцессУсловие процессаТеплоемкость CПоказатель политропы nУравнение процесса из политропы
Изобарныйp = constC = C_pn = (C_p - C_p)/(C_p - C_v) = 0p * V^{0} = const ⇒ p = const
ИзотермическийT = constC = ±∞n = lim_{C→∞}(1 - C_p/C)/(1 - C_v/C) = 1p * V^{1} = const ⇒ p * V = const
АдиабатическийdQ = 0C = 0n = (0 - C_p)/(0 - C_v) = C_p/C_v = γp * V^{γ} = const (ур-ние Пуассона)
ИзохорныйV = constC = C_vn = (C_v - C_p)/(C_v - C_v) = -R / 0 = ∞p^{1/∞} * V = const ⇒ V = const

Вопрос 12. Обратимые и необратимые процессы. Понятие энтропии термодинамической системы. Свойства энтропии. Второй закон термодинамики. Формула Больцмана. Порядок и беспорядок в природе. Третий закон термодинамики. Расчёт количества теплоты через энтропию.

1. Обратимые и необратимые процессы

Процесс распространения частиц (молекул) макросистемы без внешнего воздействия оказывается необратимым, так как обратный ему процесс самопроизвольного сосредоточения всех частиц в одной части объема крайне маловероятен (явление флуктуации). Процессы переноса в физической кинетике всегда необратимы.

2. Понятие энтропии и формула Больцмана

  • Микросостояние — конкретное расположение отдельных частиц системы по ячейкам координатного пространства и пространства импульсов; это самое точное описание системы.
  • Макросостояние — состояние термодинамической системы, характеризуемое макропараметрами (P, V, T). Одно макросостояние реализуется огромным множеством микросостояний.
  • Статистический вес (Ω) — число различных микросостояний, посредством которых реализуется данное макросостояние.
  • Энтропия Больцмана (S) — функция состояния системы, являющаяся мерой хаоса и определяемая формулой:
S = k * ln(Ω)

где k = 1,38 * 10^{-23} Дж/К — постоянная Больцмана.

3. Порядок и беспорядок в природе

Система самопроизвольно переходит из менее вероятного (более упорядоченного, где Ω мало) в более вероятное состояние (менее упорядоченное, хаотичное, где Ω максимально). Рост энтропии означает переход системы от порядка к беспорядку.

4. Свойства энтропии

  1. Аддитивность: общая энтропия системы равна сумме энтропий ее частей (S_сист = S_A + S_B).
  2. Функция состояния: изменение энтропии (dS) определяется только начальным и конечным состояниями системы.
  3. В ходе обратимого процесса в изолированной системе: dS = dQ / T.
  4. В ходе необратимого процесса энтропия изолированной системы строго возрастает: dS > dQ / T.
  5. Энтропия изолированной системы, находящейся в состоянии равновесия, максимальна.

5. Второй и Третий законы термодинамики

  • Второй закон термодинамики (закон возрастания энтропии): Энтропия изолированной термодинамической системы может только возрастать, либо, по достижении максимального значения (в состоянии равновесия), оставаться постоянной: dS ≥ 0.
  • Третий закон термодинамики (Теорема Нернста): При стремлении абсолютной температуры системы к нулю (T → 0) тепловое движение прекращается, система переходит в единственное базовое микросостояние (Ω = 1), следовательно, ее энтропия стремится к нулю: S → 0.

6. Расчёт количества теплоты через энтропию

Для элементарного обратимого процесса связь имеет вид: dQ = T * dS. Полное количество теплоты находится интегрированием:

Q = ∫ T * dS

Вопрос 13. Циклические процессы. Тепловая машина. Цикл Карно в координатах (P, V) и (T, S). Вывод формулы КПД. Теоремы Карно. Различные формулировки второго закона термодинамики. Холодильная машина.

1. Циклические процессы и тепловая машина

Циклический процесс — круговой термодинамический процесс, возвращающий систему в исходное состояние. Тепловая машина за цикл получает количество теплоты Q_1 от нагревателя (T_1), совершает полезную работу A и отдает теплоту Q_2 холодильнику (T_2). Полезная работа за цикл равна:

A = Q_1 - Q_2

2. Цикл Карно в координатах (P, V) и (T, S)

Цикл Карно состоит из двух изотерм (1→2 при T_1=const и 3→4 при T_2=const) и двух адиабат (2→3 и 4→1, где Q=0, dS=0).

📊 Цикл Карно (P-V диаграмма)

1→2: изотермическое расширение (Q₁)
2→3: адиабатическое расширение
3→4: изотермическое сжатие (Q₂)
4→1: адиабатическое сжатие

📊 Цикл Карно (T-S диаграмма)

КПД = 1 − T₂/T₁ = (T₁−T₂)/T₁

3. Вывод формулы КПД цикла Карно

1. Работа в координатах (T, S) — это площадь прямоугольника: A = (T_1 - T_2) * (S_2 - S_1).
2. Количество теплоты, полученное от нагревателя на изотерме 1→2: Q_1 = T_1 * (S_2 - S_1).
3. Коэффициент полезного действия (КПД):

η = A / Q_1 = [(T_1 - T_2) * (S_2 - S_1)] / [T_1 * (S_2 - S_1)] = (T_1 - T_2) / T_1 = 1 - T_2 / T_1

  • По Кельвину: «Невозможны такие процессы, единственным конечным результатом которых явилось бы отнятие от некоторого тела определенного количества теплоты и превращение этой теплоты полностью в работу».

5. Холодильная машина

Если запустить цикл в обратном направлении, машина станет холодильной. Она за счет внешней работы A забирает тепло Q_2 у холодного тела и отдает тепло Q_1 горячему. Ее эффективность описывается холодильным коэффициентом:

ε_хол = Q_2 / A

Вопрос 14. Расчёт изменения энтропии в процессах идеального газа (при постоянных P, V, T, Q), при нагревании и плавлении.

Расчет изменения энтропии ΔS = S_2 - S_1 ведется через интегрирование выражения dS = dQ / T для обратимых путей. Из первого начала ТД: dQ = dU + p*dV = ν*C_v*dT + p*dV.

  • 1. Изохорный процесс (V = const ⇒ dV = 0):
    Работа dA = 0, следовательно, dQ = dU = ν * C_v * dT.
    ΔS = ∫ (ν * C_v * dT) / T = ν * C_v * ln(T_2 / T_1)
  • 2. Изобарный процесс (P = const):
    По определению теплоемкости при постоянном давлении dQ = ν * C_p * dT.
    ΔS = ∫ (ν * C_p * dT) / T = ν * C_p * ln(T_2 / T_1)
  • 3. Изотермический процесс (T = const ⇒ dU = 0):
    Изменение внутренней энергии dU = 0, тогда dQ = dA = p * dV. Из уравнения состояния p = ν*R*T / V.
    ΔS = ∫ (ν * R * T / V) * (dV / T) = ν * R * ln(V_2 / V_1)
    С учетом закона Бойля-Мариотта также справедливо: ΔS = ν * R * ln(P_1 / P_2).
  • 4. Адиабатический процесс (Q = const ⇒ dQ = 0):
    Процесс является изоэнтропийным:
    ΔS = ∫ 0 / T = 0   ⇒   S = const
  • 5. При нагревании тела (в интервале температур от T_1 до T_2):
    Для тела массы m с удельной теплоемкостью c: dQ = m * c * dT.
    ΔS = ∫ (m * c * dT) / T = m * c * ln(T_2 / T_1)
  • 6. При плавлении (фазовый переход):
    Плавление происходит при постоянной температуре T_пл. Поглощаемое тепло Q = λ_пл * m (где λ_пл — удельная теплота плавления).
    ΔS = Q / T_пл = (λ_пл * m) / T_пл

Вопрос 15. Силы и потенциальная энергия межмолекулярного взаимодействия. Реальные газы. Уравнение Ван-дер-Ваальса для одного моля и произвольного количества газа. Физический смысл поправок а и b. Внутренняя энергия газа Ван-дер-Ваальса.

1. Силы и потенциальная энергия межмолекулярного взаимодействия

В отличие от идеального газа, между молекулами реального газа действуют силы межмолекулярного взаимодействия. Они зависят от расстояния между молекулами:

  • На больших расстояниях преобладают силы притяжения (из-за ван-дер-ваальсовых сил).
  • На очень малых расстояниях преобладают силы отталкивания (из-за перекрытия электронных оболочек).
  • Внутренняя энергия реального газа состоит из кинетической энергии молекул и потенциальной энергии их взаимодействия: U = ν * C_v * T + U_пот.

2. Уравнение Ван-дер-Ваальса

Является приближенным уравнением состояния реального газа. Записывается в следующем виде:

  • Для 1 моля газа:
    (p + a / V_m²) * (V_m - b) = R * T
  • Для произвольного количества вещества (ν моль):
    (p + ν² * a / V²) * (V - ν * b) = ν * R * T

3. Физический смысл поправок a и b

  • Поправка 'a' (внутреннее давление): Учитывает взаимное притяжение молекул газа. Молекулы у стенок сосуда притягиваются молекулами изнутри объема, что уменьшает давление на стенку. Величина (a / V_m²) — это внутреннее давление реального газа.
  • Поправка 'b' (собственный объем): Учитывает силы отталкивания на малых расстояниях и представляет собой учетверенный собственный объем всех молекул газа. Это та часть объема сосуда, которая недоступна для движения молекул.

4. Внутренняя энергия газа Ван-дер-Ваальса

Потенциальная энергия притяжения молекул отрицательна и обратно пропорциональна объему. Согласно лекционному материалу, полная внутренняя энергия газа Ван-дер-Ваальса имеет вид:

U = ν * C_v * T - (ν² * a / V)

Она зависит не только от температуры T (как у идеального газа), но и от занимаемого объема V.

Вопрос 16. Изотермы Ван-дер-Ваальса и их анализ. Сравнительный анализ теоретических и экспериментальных изотерм. Метастабильные состояния. Критические параметры. Критическое состояние вещества.

1. Анализ теоретических изотерм Ван-дер-Ваальса

Уравнение Ван-дер-Ваальса относительно объема является уравнением 3-й степени. При температурах ниже критической (T < T_кр) график изотермы имеет характерную волну (S-образный изгиб) с локальными минимумом и максимумом.

2. Сравнение с экспериментальными изотермами

На реальном опыте (эксперименте) сжатие газа приводит к его сжижению, и на графике наблюдается строго горизонтальный участок (прямая AB), где давление остается постоянным — это давление насыщенного пара P_нас. Вдоль этой прямой сосуществуют две фазы: жидкость и газ.

3. Метастабильные состояния

Теоретическая кривая Ван-дер-Ваальса частично реализуется на практике в виде неустойчивых (метастабильных) состояний:

  • Участок (p'', V'') — перегретая жидкость: чистая жидкость без центров парообразования, доведенная до давления ниже давления насыщенного пара при данной температуре.
  • Участок (p', V') — пересыщенный (переохлажденный) пар: чистый пар без центров конденсации, давление которого выше давления насыщенного пара.

4. Критическое состояние и критические параметры

При повышении температуры изгиб теоретической изотермы сглаживается. При критической температуре (T = T_кр) волна превращается в единственную точку перегиба — критическую точку.

  • Критическое состояние: Состояние вещества, при котором исчезает физическое различие между жидкой и газообразной фазами (их плотности, энтропии и объемы становятся одинаковыми). Выше T_кр вещество может находиться только в газообразном состоянии (сверхкритический флюид) и его невозможно сжижить никаким давлением.
  • Критические параметры вычисляются через поправки (a, b) из условия равенства нулю первой и второй производной давления по объему:
    V_кр = 3*b,   p_кр = a / (27*b²),   T_кр = 8*a / (27*R*b)

Вопрос 17. Явления на границе раздела жидкой и газообразной фаз. Поверхностное натяжение. Термодинамика поверхностного слоя. Свободная поверхностная энергия. Внутренняя энергия поверхностного слоя, формула Кельвина. Теплота образования плёнки.

1. Поверхностное натяжение и свободная поверхностная энергия

Молекулы внутри жидкости окружены другими молекулами равномерно со всех сторон (равнодействующая сил равна нулю). Молекулы на поверхности притягиваются только внутрь жидкости. Для увеличения поверхности раздела фаз необходимо совершить работу против этих внутренних сил:

dA' = σ * dF

где σ — коэффициент поверхностного натяжения, dF — изменение площади. Свободная энергия поверхностного слоя (потенциал Гельмгольца) при T = const равна: Ψ = σ * F.

2. Термодинамика поверхностного слоя (мыльной плёнки)

Запишем первое начало термодинамики для процесса изменения площади поверхности: dQ = dU - dA'. Так как для обратимого процесса dQ = T * dS, уравнение внутренней энергии мыльной пленки принимает вид:

dU = T * dS + σ * dF

Дифференциал свободной энергии Ψ = U - T*S равен: dΨ = σ * dF - S * dT. Отсюда частная производная поверхностного натяжения по площади при постоянной температуре: (∂Ψ / ∂F)_T = σ.

3. Внутренняя энергия поверхностного слоя (Формула Кельвина)

Полная внутренняя энергия поверхностного слоя U складывается из свободной поверхностной энергии Ψ и связанной энергии (теплоты). Полная формула Кельвина имеет вид:

U = σ * F - T * (∂σ / ∂T) * F

Поскольку с ростом температуры поверхностное натяжение уменьшается ((∂σ/∂T) < 0), член -T*(∂σ/∂T) является положительным.

4. Теплота образования плёнки

При изотермическом увеличении площади пленки (например, вытягивании мыльной пленки) к ней необходимо подводить теплоту Q из окружающей среды, чтобы температура оставалась постоянной:

Q = -T * (∂σ / ∂T) * F

Вопрос 18. Давление под искривлённой поверхностью жидкости. Формула Лапласа для сферической и цилиндрической поверхностей, мыльного пузыря. Капиллярные явления. Закон Жюрена.

1. Избыточное давление под искривленной поверхностью (Формула Лапласа)

Искривленная поверхность жидкости стремится сократиться под действием сил поверхностного натяжения, создавая дополнительное (избыточное) давление Δp по сравнению с плоской поверхностью. В общем виде формула Лапласа для двух главных радиусов кривизны R₁ и R₂ записывается как:

Δp = σ * (1/R₁ + 1/R₂)

2. Частные случаи формулы Лапласа

  • Для сферической поверхности (мениск, капля радиуса R): так как R₁ = R₂ = R, получаем:
    Δp = 2σ / R
  • Для цилиндрической поверхности (кривизна только по одной оси, R₂ = ∞):
    Δp = σ / R
  • Для мыльного пузыря: Пузырь имеет две поверхности раздела (внутреннюю и внешнюю), каждая из которых вносит вклад в давление:
    Δp = 4σ / R

3. Капиллярные явления и закон Жюрена

В узких трубках (капиллярах) радиуса 'a' образуется искривленный мениск жидкости радиуса R. Избыточное лапласовское давление заставляет жидкость подниматься или опускаться до тех пор, пока оно не уравновесится гидростатическим давлением столба жидкости высотой h:

Δp = ρ * g * h   ⇒   2σ / R = ρ * g * h

Связь радиуса мениска R с радиусом капилляра 'a' через краевой угол смачивания θ: R = a / cosθ. Подставив это в уравнение, получаем закон Жюрена для высоты поднятия жидкости:

h = (2σ * cosθ) / (ρ * g * a)
Если θ < 90° (жидкость смачивает стенки, мениск вогнутый) ⇒ h > 0 (жидкость поднимается).
Если θ > 90° (жидкость не смачивает стенки, мениск выпуклый) ⇒ h < 0 (жидкость опускается).

Вопрос 19. Фазовые переходы первого и второго рода. Тройная точка. Уравнение Клапейрона-Клаузиуса и его анализ (для процессов плавления и испарения).

1. Фазовые переходы первого и второго рода

  • Фазовый переход I рода: Переход вещества из одной фазы в другую, происходящий при постоянной температуре и сопровождающийся скачкообразным изменением энтропии (ΔS ≠ 0) и объема (ΔV ≠ 0). Этот переход всегда идет с поглощением или выделением скрытой удельной теплоты перехода q₁₂ (например: плавление, кипение, сублимация).
  • Фазовый переход II рода: Переход, при котором объем и энтропия вещества меняются непрерывно (ΔS = 0, ΔV = 0), но скачкообразно меняются их производные — теплоемкость C_p, коэффициент объемного расширения и сжимаемость (например: переход металлов в сверхпроводящее состояние, переход ферромагнетика в парамагнетик в точке Кюри).

2. Тройная точка

Тройная точка — это точка на диаграмме состояний (в координатах p-T), где пересекаются кривые плавления, испарения и сублимации. В тройной точке три фазы одного и того же вещества (твердая, жидкая и газообразная) находятся в состоянии устойчивого термодинамического равновесия. Для каждого вещества значения P и T в этой точке уникальны.

3. Уравнение Клапейрона-Клаузиуса

Определяет наклон кривой равновесия между фазами на p-T диаграмме для фазовых переходов I рода. Выводится через рассмотрение обратимого цикла Карно для двухкомпонентной системы массы m:

dp / dT = q₁₂ / [T * (V₂' - V₁')]

где dp/dT — производная равновесного давления по температуре, q₁₂ — удельная теплота фазового перехода, T — абсолютная температура перехода, (V₂' - V₁') — приращение удельного объема вещества при переходе из первой фазы во вторую.

4. Анализ уравнения Клапейрона-Клаузиуса

  • Процесс испарения / кипения (жидкость → газ): Удельный объем пара всегда значительно больше удельного объема жидкости (V_пара' > V_жидк'). Теплота испарения q > 0. Следовательно, производная dp/dT > 0. С ростом внешнего давления температура кипения жидкости всегда увеличивается.
  • Процесс плавления (твердое тело → жидкость):
    • Для большинства веществ объем при плавлении растет (V_жидк' > V_тв'), поэтому dp/dT > 0 (с ростом давления температура плавления растет).
    • Для некоторых веществ (например, лед → вода, висмут, чугун) объем при плавлении уменьшается (V_воды' < V_льда'). Из-за этого разность объемов отрицательна, и производная dp/dT < 0. Это означает, что с ростом давления температура плавления льда понижается. Сильным сжатием льда при температуре T ≤ 0°C можно вызвать его плавление.

Вопрос 20. Давление под искривлённой поверхностью жидкости. Вывод формулы Лапласа. Частные случаи. Капилляры. Вывод формулы поднятия жидкости в капилляре.

1. Давление под искривлённой поверхностью — физика

Из‑за поверхностного натяжения искривлённая поверхность создаёт дополнительное давление:

2. Вывод формулы Лапласа для сферической поверхности

Рассмотрим сферическую поверхность радиуса R. Выделим малый элемент поверхности. Силы поверхностного натяжения, стягивающие элемент, уравновешиваются силой избыточного давления:

ΔP · πR² = σ · 2πR ⇒ ΔP = 2σ / R

Для произвольной поверхности с главными радиусами кривизны R₁ и R₂ обобщённая формула Лапласа:

4. Капиллярные явления. Формула Жюрена

Капилляр — узкая трубка, в которой проявляются силы поверхностного натяжения. При смачивании (θ < 90°) мениск вогнутый → жидкость поднимается; при несмачивании (θ > 90°) — опускается.

Вывод формулы поднятия жидкости:
Давление под вогнутым мениском: P = P₀ - 2σ/R. Радиус кривизны мениска связан с радиусом капилляра r и краевым углом θ: R = r / cosθ. Гидростатическое равновесие: P₀ = P + ρgh. Подстановка даёт:

h = (2σ cosθ) / (ρ g r)

При полном смачивании (θ = 0) → h = 2σ/(ρ g r).

2. Дефекты в кристаллах

  • Точечные (0D): вакансии, межузельные атомы, примеси.
  • Линейные (1D): дислокации (краевые, винтовые) — определяют пластичность.
  • Поверхностные (2D): границы зёрен, двойниковые границы.
  • Объёмные (3D): поры, трещины, включения.

Влияние на свойства: электропроводность (легирование полупроводников), механическая прочность (упрочнение дислокациями), диффузия, оптические свойства (центры окраски).

3. Классическая теория теплоёмкости твёрдых тел

Модель: каждый атом — 3 независимых гармонических осциллятора. На каждую степень свободы приходится kT (по ½kT кинетической и ½kT потенциальной энергии). Для моля:

U = 3 N_A k T = 3 R T ⇒ C_V = dU/dT = 3R ≈ 25 Дж/(моль·К)

4. Закон Дюлонга и Пти (1819)

Формулировка: Молярная теплоёмкость простых кристаллических тел при комнатной температуре приблизительно постоянна и равна 3R. Подтверждается для многих металлов (Al, Cu, Fe, Pb) при T > Θ_D (температура Дебая).
Отклонения: при низких T (C_V ∼ T³) и для лёгких элементов (алмаз, бор).

5. Закон Джоуля–Коппа (для соединений)

Формулировка: Молярная теплоёмкость химического соединения равна сумме теплоёмкостей входящих в него атомов.

Cмол(AmBn) = m·3R + n·3R = 3R(m + n)

Пример: CNaCl ≈ 3R + 3R = 6R ≈ 50 Дж/(моль·К). Приближённый закон, работает для ионных кристаллов при высоких T.

1. Фаза и фазовое равновесие

Фаза — термодинамически равновесная часть системы, однородная по составу и свойствам, отделённая от других частей поверхностью раздела. Условие равновесия фаз: равенство химических потенциалов μ₁(T,P) = μ₂(T,P). Правило фаз Гиббса для однокомпонентной системы: f = 1 − φ + 2, где φ — число фаз.

2. Фазовые переходы первого и второго рода

  • I рода: скачкообразное изменение объёма и энтропии, выделяется/поглощается теплота перехода. Примеры: плавление, испарение, сублимация.
  • II рода: объём и энтропия непрерывны, но скачком меняются теплоёмкость, коэффициент теплового расширения, сжимаемость. Примеры: переход ферромагнетик‑парамагнетик (точка Кюри), переход в сверхпроводящее состояние.

3. Полиморфизм

Способность вещества существовать в нескольких кристаллических модификациях. Примеры: углерод (алмаз, графит, фуллерены); железо (α‑Fe, γ‑Fe, δ‑Fe); лёд (известно 18 фаз).

5. Уравнение Клапейрона–Клаузиуса

Определяет наклон кривой равновесия фаз на (P,T)‑диаграмме:

dP/dT = λ / (T·Δv)

где λ — удельная теплота перехода, Δv — изменение удельного объёма.

  • Для испарения (vпар ≫ vж, пар считаем идеальным): dP/dT = (rP)/(R T²) → интегрирование даёт ln P = − (rM)/(R T) + const.
  • Для плавления воды (vж < vл → dP/dT < 0): температура плавления льда понижается с ростом давления (коньки, ледники).

6. Тройная точка и диаграмма состояний

Тройная точка — единственное сочетание (Pтр, Tтр), при котором сосуществуют три фазы. Для воды: Tтр = 273,16 К (0,01°C), Pтр = 611,7 Па. Используется для калибровки термометров.

📈 Фазовая диаграмма (P-T) для однокомпонентного вещества

Линии равновесия фаз разделяют области устойчивого существования твёрдой, жидкой и газообразной фаз. В тройной точке сосуществуют все три фазы.

Практическое значение: криогеника (сжижение газов), металлургия (термообработка), климатология (фазовые переходы воды в атмосфере), пищевая промышленность (сублимационная сушка).
